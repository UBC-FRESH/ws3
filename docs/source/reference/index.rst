Data Contracts
--------------

:doc:`contracts/index` contains the compact technical contracts that define
the data formats, runtime invariants, and agent-facing specifications for ws3.
These pages are the primary reference for LLM coding agents working in this
repository.

API Reference
-------------

:doc:`api/index` provides the full Python API documentation, generated from
docstrings. This is the reference for developers extending or integrating
with ws3.

Data Formats
------------

:doc:`data_formats` describes the input and output data formats in detail,
including field definitions, valid ranges, and example files.

Module Index
------------

:doc:`module_index` provides a complete index of all ws3 modules and their
contents, useful for navigating the API reference.
