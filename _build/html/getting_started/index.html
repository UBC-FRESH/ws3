What You Will Learn

By the end of this section you will be able to:

  • Install ws3 and its dependencies in a clean Python environment.

  • Prepare the minimum input data required to run a simulation.

  • Execute a complete wood supply simulation scenario.

  • Interpret the basic output and verify that results make sense.

Prerequisites

Before you begin, you should have:

  • Python 3.10 or later installed.

  • Basic familiarity with the command line (terminal or PowerShell).

  • A working understanding of what a wood supply model does (if not, start with the Chapter 1: Forest Estate Models chapter first).

Estimated Time

  • Installation and environment setup: 15–30 minutes

  • Quickstart and first model walkthrough: 45–60 minutes

  • Architecture orientation: 20–30 minutes
